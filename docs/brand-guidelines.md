# حوِّل | Hawel — Brand Guidelines

## Brand Identity

- **Name:** حوِّل | Hawel
- **Tagline:** Sudan's first developer-grade payments infrastructure
- **Audiences:** Merchants, local partners, CBOS regulators, international investors, diaspora developers

## Logo: "The Flow Loop"

The Arabic letter ح (Ha) — first letter of حوِّل — is stylized into a continuous loop that doubles as a currency transfer arrow circuit. The loop is open on one side, suggesting flow outward (money moving), never closed (no hoarding — Sharia-compliant). The shape also reads as a payment circuit node diagram when abstracted.

### Logo Variations

| Variant | Usage |
|---------|-------|
| Default (primary bg, gold strokes) | Light mode header, footer, primary contexts |
| Inverted (gold bg, nile strokes) | Dark/gold sections, accent areas |
| Mark only (no text) | Favicon, small UI elements, loading states |

### Clear Space

Maintain at minimum the height of the mark around all sides.

## Tone

- **Merchants:** Outcome-focused — "accept payments, not architecture"
- **Investors:** Technical credibility + market opportunity + regulatory alignment
- **Developers:** API-first, sandbox access, SDK availability
- **General:** Trust, cultural rootedness, Sharia compliance
